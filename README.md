# Shoe Sales Analysis

## 📌 Project Overview

This project focuses on analyzing Shoe Sales data using Python to uncover sales trends, product performance, and revenue insights. Through data cleaning, exploratory data analysis (EDA), and visualizations, the project aims to provide meaningful business insights that can support data-driven decision-making.

---

## 🎯 Objectives

* Analyze overall sales performance.
* Identify top-performing products.
* Understand revenue trends and patterns.
* Explore relationships between different sales variables.
* Generate actionable business insights through data visualization.

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 📊 Project Workflow

### 1. Data Cleaning

* Checked for missing values.
* Removed duplicates.
* Corrected data types.
* Prepared the dataset for analysis.

### 2. Exploratory Data Analysis (EDA)

* Analyzed sales distribution.
* Examined product performance.
* Explored revenue trends.
* Identified key business patterns.

### 3. Data Visualization

Created visualizations such as:

* Histograms
* Bar Charts
* Box Plots
* Correlation Heatmaps
* Sales Trend Charts

---

## 🔍 Key Insights

* Identified top-selling shoe categories.
* Analyzed revenue contribution by products.
* Discovered sales trends and patterns.
* Highlighted business opportunities through data analysis.
